## 📘 About

This repository is a central hub for:
- ✍️ Technical articles on backend concepts
- 🗒️ Notes from learning and experience
- 📑 Cheatsheets for quick reference
- 💡 Code snippets and best practices

Built to support both **learning** and **real-world backend development** using technologies like Java, Spring Boot, Microservices, Databases, Docker, and more.

4. Commit and push: `git commit -m "Add notes on topic XYZ"` and `git push origin feature/topic-name`
